基于「清爽首页」重构的首页, 推荐与动态改为网格平铺, 不再需要左右翻页.

- 推荐: 一次展示整批视频; `换一批` 会保留最近 5 批历史, 可用 `上一批` 找回; `再来一批` 在下方追加; 标题旁可按 推荐顺序 / 播放 / 弹幕 / 时长 / 发布时间 排序, 再点一次切换升降序.
- 动态: 按日期分组的时间线, 滚动到底部自动加载更早的动态; 记录已读位置, 新视频带 NEW 标记; 顶部 UP 头像条可只看某个 UP.
- 卡片: 悬停时左右移动鼠标可预览视频画面; 推荐卡片可一键屏蔽 UP 主 (写入「屏蔽黑名单up主」的名单, 可撤销).
- 向下滚动后顶部会出现悬浮导航, 可在推荐 / 动态之间跳转.

请注意:
- 此功能与 `清爽首页`, `极简首页` 互斥, 请勿同时使用. 首次启用时会自动迁移原版清爽首页的设置.
- 屏蔽 UP 只修改本地脚本设置, 不会调用 B 站账号的拉黑接口. 安装了「屏蔽黑名单up主」时与其共用名单.
